# Profile maintenance

This repository supplies the profile README displayed on [Adarsh Prakasan's GitHub profile](https://github.com/adarshprakasan). The profile content and visual layout are maintained in `README.md`.

## Update workflow

1. Edit the selected-work descriptions and links when public project capabilities change.
2. Check linked repositories, the portfolio, résumé/contact destinations, and externally rendered badge images.
3. Preview the Markdown and HTML tables on GitHub, including at a narrow viewport.
4. Keep descriptions aligned with the source project's current release status and limitations.

The profile renders directly on GitHub and has no local package installation, build pipeline, or test suite. The separate portfolio is hosted at [adarshprakasan.vercel.app](https://adarshprakasan.vercel.app).

Only publish information intended for the public profile. Private repository documentation remains in its own repository.
